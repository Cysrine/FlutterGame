# Retro Asteroid Shooter 🚀

A retro, pixelated, infinite-downfall asteroid shooter game built using **Flutter** and the **Dart SDK**. This cross-platform game features endless, fast-paced action where you pilot a spaceship, dodge and destroy falling asteroids, and try to survive as long as possible!

## 🎮 Gameplay Mechanics
* **Endless Action:** The game continuously drops asteroids from the top of the screen.
* **Progressive Difficulty:** As time passes and your score increases, the falling asteroids accelerate, making the game increasingly challenging.
* **Health System:** The spaceship has a limited amount of health. Taking hits from asteroids will reduce it.
* **Game Over:** The game ends as soon as the spaceship's health reaches zero. Try to beat your highest score!

## ✨ Features
* **Retro Pixel Art Style:** Enjoy a nostalgic, arcade-like graphical experience.
* **Cross-Platform:** Write once, play anywhere. Thanks to the Flutter framework, the game is built to run on Android, iOS, Web, and Desktop platforms.
* **Dynamic Scoring:** Points are awarded for surviving and destroying the endless waves of asteroids.

## 🛠️ Tech Stack
* **Framework:** [Flutter](https://flutter.dev/)
* **Language:** [Dart](https://dart.dev/)
